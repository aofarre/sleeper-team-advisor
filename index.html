PRIVATE CONNECTION

Your Sleeper leagues

READ-ONLY API

League IDs and your username are stored only in this browser. The app calls documented public Sleeper endpoints directly; no account credentials are requested or stored.

IMPORTANT LIMITATION

Expert inputs stay yours

Sleeper’s public API can provide league, roster, matchup, player-directory, and transaction data. It does not provide trusted real-time expert projections, injury analysis, or news. This app never invents those signals: projection fields and risk notes are manual inputs, and matchup projections appear only if Sleeper actually supplies them.

No context imported

The deployed Tuesday baseline is a timestamped public Sleeper player-directory snapshot. It can establish player status and identity, but cannot establish league-specific availability, injury news, or projections. Add those only through a lawful manual or licensed-provider snapshot that names its source.

Source configuration, endpoint URL, and imported context are local to this browser. No provider credential can be entered or stored here.
